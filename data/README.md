# Data

This project uses the City Hotel (H2) Hotel Booking Demand dataset.

- Expected size: 79,330 rows × 31 variables
- Required dataset: `H2.csv`
- H2 must be used alone for the required experiments.

Source:
https://raw.githubusercontent.com/afaq-ahmad/Hotel-booking-demand-Case-Study/master/H2.csv
