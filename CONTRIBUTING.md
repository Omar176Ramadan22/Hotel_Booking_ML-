# Contribution workflow

1. Pull the latest `main`.
2. Create a focused branch, e.g. `feature/eda`.
3. Make one meaningful piece of work.
4. Test the change.
5. Commit with a descriptive message.
6. Push the branch.
7. Open a pull request and review before merging.

Example commit messages:
- `Add initial H2 data inspection`
- `Add missing-value analysis`
- `Add cancellation EDA`
- `Add preprocessing pipeline`
